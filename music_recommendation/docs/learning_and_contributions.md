# 学习、引用与真实贡献

## 每位成员应能回答

1. 为什么 weight 不是评分？未听过为什么不是明确负样本？
2. 为什么标签时间不能当收听时间？当前拆分支持怎样的结论？
3. 训练、验证、测试分别做什么？为什么阶段一不看测试分数？
4. 对一位用户手算 Precision@3、Recall@3、NDCG@3，并运行对应单元测试。
5. ItemCF 的共现、余弦、收缩与邻居截断如何计算？为什么 X @ S 不是 X @ S.T？
6. 为什么保留冷艺人会降低指标？为什么不能直接删除他们只报好看的分数？
7. 为什么标签全量汇聚可能泄漏？为什么双塔不是简单“加标签”的别名？
8. 为什么本验证结果不能证明线上满意度改善，也不能证明最终神经网络一定更好？
