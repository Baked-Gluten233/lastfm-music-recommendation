# 固定实验协议（阶段一冻结）

## 信息与拆分

- 正反馈：`user_artists.dat` 中 weight > 0 的用户–艺人对；先审计缺失、重复、非法计数与目录映射。当前未删交互，未做 k-core。模型使用二值反馈；次数仅用于 EDA，不作为负标签或评分。
- catalogue：`artists.dat` 全部 17,632 个静态目录 ID。目录存在不等于模型见过该艺人的训练反馈。只用目录 ID 做映射，不使用测试交互计算热度、相似度、特征或归一化。
- 对每位 degree >=5 的用户，用 `SeedSequence([42,userID])` 对按 artistID 排序的记录随机排列。验证、测试各取 max(1,floor(n/10))，其余训练。低于 5 的用户全部进入训练，不计验证/测试。不是时间切分，也不声称未来预测。
- 不人为保证物品在训练出现，不用验证/测试修复覆盖。所有模型沿用同一 CSV 和 SHA256。阶段一写入测试文件、检查互斥和完整性后不计算测试指标。

## 统一评价

- 每位验证用户：候选为**全部目录减去该用户训练中出现的艺人**。其他用户听过的艺人不排除；本用户测试艺人也不作为“已知答案”提前过滤。没有抽样负例，约 1.76 万候选/用户。
- 主指标：用户宏平均 NDCG@10。辅助：Precision/Recall/HitRate @10、@20，以及所有用户 Top-10 推荐集合占目录大小的 CatalogueCoverage@10。
- Precision@K = 命中数/K；Recall@K = 命中数/本用户验证正反馈数；DCG@K = 命中指示值除以 log2(rank+1) 的和；IDCG 取 min(K,正反馈数) 个理想命中。用户等权，不对全部命中做微平均。
- 排名相同分数时按训练用户频次降序，再按原始 artistID 升序。ItemCF 零分候选因此带热门回退，所有模型采用同一 tie-break。未知艺人仍在候选；零训练项也可能因 tie-break 入榜，不能声称其召回在数学上必定为零。
- 冷目标：训练中没有任何听众的艺人。保留在指标分母，不删除失败案例。新用户不是本协议的评测场景；低活跃用户单列，不把他们说成新用户。
- 用户 bootstrap 95% 区间只描述当前验证用户样本不确定性，不覆盖不同随机拆分、模型随机种子或验证集调参赢家偏差；不当成最终统计显著性结论。

## 基线机制与选择

Popularity 按训练中听过该艺人的不同用户数排序，不累加播放次数。

ItemCF：X 是二值用户×艺人训练矩阵；c(i,j)=XᵀX 的非对角共现。s(i,j)=c(i,j)/sqrt(n_i n_j)，再乘 c(i,j)/(c(i,j)+lambda)。每个源艺人只保留 top-N 邻居；矩阵变为有向截断。推荐分数 X @ S，即把用户训练历史每个源艺人的邻居贡献相加。冷艺人的余弦定义为零，不除以零。

验证网格：N∈{20,50,100}，lambda∈{0,10}。按验证 NDCG@10 选择；完全相同则先选小 N、再小 lambda。该调参不是 Model 1/2/3。未根据测试选择任何参数。
